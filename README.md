# Theo’s Day Trading Network

## Preview
Open index.html in a browser. The site needs no build, installation, backend, or API keys. Internet access loads optional Google Fonts; system fonts work offline. Discord and YouTube open in new tabs.

## Deploy to a new static site
1. Keep index.html, styles.css, and script.js together.
2. Create a NEW static project on your hosting provider (for example Cloudflare Pages, Netlify, or GitHub Pages). Do not select or overwrite the existing NextLevel project.
3. Upload the dtn folder using the host’s static-file upload, or commit it to a new repository. For repository hosting, select no framework, no build command, and the folder containing index.html as the publish directory.
4. Preview the generated hosting URL on mobile and desktop. Confirm every Discord and YouTube link and review copy with Theo before a public launch.
5. Add your domain in the hosting dashboard and use the exact DNS records the host provides. Enable HTTPS. Domain/hosting credentials are not required for this local deliverable.
